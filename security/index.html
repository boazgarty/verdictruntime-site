Security and authorisation

How Verdict Runtime keeps testing safe: nothing runs without your written scope, and the method is held to the standard it sells.

Authorisation

Nothing runs without your written scope

Every agent that can send traffic checks the target against a scope file your team signs off. The check is compiled in, not a setting. No entry, no run.

    Reading source needs only a repository entry.
  • ›
