Verdict Runtime vs CodeQL and a commercial SAST tool

How Verdict Runtime compares with GitHub CodeQL and a leading commercial SAST tool on deliberately vulnerable applications with labelled flaws, scored against each app's own answer key.

Benchmark · 2026-10-24

More labelled flaws found than a leading commercial SAST tool and GitHub CodeQL. Then we keep going.

We ran Verdict Runtime head to head against a leading commercial SAST tool and GitHub CodeQL on twelve deliberately vulnerable applications across six languages. Each app was scored against an answer key built from its own labels. Static scanning was only the first round.

Round 1b: more real flaws, on a benchmark built to trip scanners up

Most of this industry-standard Python benchmark is bait: of its 1,230 test cases, 63% are safe code dressed up to look vulnerable. A good scanner finds the real flaws and stays quiet on the rest. That is exactly how it is scored.
